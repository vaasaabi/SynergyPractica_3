# Приложения к кейс-задачам практики

Исходный код к практическим кейсам.

## Состав
| Папка | Кейс | Что это |
|-------|------|---------|
| `biznotes/` | №4 | Мобильное приложение «BizNotes» (Flutter, Android/iOS) для ведения заметок на совещаниях. Хранение SQLite + файловая система. |
| `expert-system/` | №3 | Прототип экспертной системы диагностики неисправностей НКУ на оболочке CLIPS. |

Кейс №5 (юзабилити-тестирование) отдельного кода не требует — тестируется
приложение из кейса №4.

## Быстрый старт
**BizNotes (Flutter):**
```bash
cd biznotes
flutter create .      # досоздать папки android/ios под вашу версию Flutter
flutter pub get
flutter run           # или: flutter build apk --release
```

**Экспертная система (CLIPS 6.4):**
```
(load "expert-system/expert_system_nku.clp")
(reset)
(run)
```

Подробности — в `README.md` внутри каждой папки.
