# BizNotes — приложение для ведения заметок (кейс-задача №4)

Кроссплатформенное мобильное приложение (Android / iOS) на **Flutter (Dart)** для
создания, редактирования, удаления и поиска заметок во время совещаний, планёрок и
конференций.

## Возможности
- Создание заметки: заголовок, дата, время, содержание.
- Редактирование и удаление (с подтверждением).
- Поиск по ключевым словам в заголовке и содержании (а также по дате/времени).
- **Два способа хранения** (переключаются в «Настройках»):
  - реляционная база данных **SQLite** (пакет `sqflite`);
  - **файловая система** устройства — каждая заметка отдельным JSON-файлом
    (`path_provider` + `dart:io`).
- Заготовка облачной синхронизации (Firebase) — демонстрационный переключатель.

## Запуск
Требуется установленный Flutter SDK (canal stable, Flutter ≥ 3.10).

```bash
# 1. В каталоге проекта создать платформенные папки (android/ios) под вашу версию Flutter:
flutter create .

# 2. Установить зависимости:
flutter pub get

# 3. Запустить на эмуляторе/устройстве:
flutter run

св# 4. Собрать APK для Android:
flutter build apk --release
# готовый файл: build/app/outputs/flutter-apk/app-release.apk
```
> `flutter create .` только досоздаёт папки `android/`, `ios/` и т. п., не затрагивая
> `lib/` и `pubspec.yaml`.

## Как протестировать
1. Установить APK на Android 8.0+ или запустить проект в эмуляторе / на симуляторе iOS.
2. Создать заметку (заголовок, дата, время, содержание) — проверить появление в списке.
3. Открыть заметку, изменить содержание, сохранить — проверить обновление.
4. Выполнить поиск по ключевому слову — проверить фильтрацию.
5. Удалить заметку — проверить исчезновение из списка.
6. В «Настройках» переключить хранилище с SQLite на файловую систему и повторно
   проверить сохранение/чтение заметок в обоих режимах.
