# Экспертная система диагностики НКУ (кейс-задача №3)

Прототип экспертной системы на оболочке **CLIPS 6.4** для диагностики типовых
неисправностей шкафов управления и низковольтных комплектных устройств (НКУ).

- База знаний: факты (`deftemplate признак`) и правила (`defrule R-01 … R-06`)
  с коэффициентами достоверности (CF).
- Механизм вывода: прямой (алгоритм Rete), управляемый данными опрос.
- Интерфейс: диалог «вопрос–ответ» с подсистемой объяснений (какое правило
  привело к заключению).

## Запуск
Скачайте CLIPS 6.4 (https://clipsrules.net) или используйте онлайн-CLIPS,
затем в среде CLIPS выполните:
```
(load "expert_system_nku.clp")
(reset)
(run)
```
Отвечайте на вопросы вариантами `да` / `нет`.

### Пример сеанса
```
Есть ли напряжение на входе шкафа? (да/нет) да
Появляется ли напряжение на выходе? (да/нет) нет
Срабатывает ли автоматический выключатель при пуске? (да/нет) да

---- Заключение -------------------------------------------
Вероятная причина: Короткое замыкание в силовой цепи нагрузки
Достоверность (CF): 0.85
Рекомендация:      Проверить кабельную линию и клеммы нагрузки, изоляцию
Пояснение:         сработало правило R-03
```
